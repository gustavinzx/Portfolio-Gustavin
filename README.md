# Portfólio — Gustavo Silva

Site estático (HTML + CSS + JS puro), sem build.

- `index.html` — estrutura das 4 telas (Intro · Perfil · Projetos · Contato)
- `style.css` — visual (dark navy, brilho azul, acento vermelho)
- `script.js` — **edite o array `PROJECTS`** para adicionar/remover projetos; `SKILLS` e `LANGS` controlam tecnologias e barras
- `assets/foto.jpg` — sua foto (substitua mantendo o nome)
- `assets/projetos/` — imagens dos projetos (nomes em `assets/projetos/LEIA-ME.txt`). Sem imagem → capa gerada automaticamente.

## Rodar
Abra o `index.html` no navegador.

## Publicar no GitHub Pages
1. Crie o repositório `gustavinzx.github.io` e envie estes arquivos.
2. Settings → Pages → Branch `main` / root.
3. Acesse https://gustavinzx.github.io
